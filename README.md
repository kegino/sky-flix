# Sky Flix — Streaming IPTV Premium em 4K

Plataforma oficial do **Sky Flix** (`skyflix.website`), provedor de streaming IPTV de alta estabilidade com mais de 35.000 canais ao vivo, filmes de cinema, séries completas e esportes em 4K sem travamento.

## 🚀 Tecnologias

- **Framework**: TanStack Start + Vite + React 19
- **Estilização**: Tailwind CSS v4 + Radix UI + Lucide React
- **SEO & Otimização**: Schema.org estruturado (Product, FAQPage, HowTo, BlogPosting, OfferCatalog), OpenGraph completo, Canonical Tags dinâmicas, Sitemap XML e RSS feed nativo.
- **Performance**: Backdrop cinematográfico Avatar: The Way of Water otimizado em WebP, paleta Midnight Cyan & Solar Gold de altíssimo contraste e legibilidade.

## 🛠️ Executando localmente

```sh
git clone https://github.com/kegino/sky-flix.git
cd sky-flix
pnpm install
pnpm dev
```

## 📦 Build para produção

```sh
pnpm build
```
